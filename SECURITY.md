# Security policy

Rugged Speech Test holds sensitive information about children (photographs, medical details, and optionally what they said), so security reports are taken seriously.

## Reporting a problem

Please report a security problem **privately**, not in a public issue. Use GitHub's private vulnerability reporting on this repository (Security, then Report a vulnerability), or contact the maintainer, Ethan Sumner, through the contact on the project's GitHub profile.

Please say what you did and what happened. **Do not include any real child's information.**

## What to expect

You will get a reply, and a fix or an explanation, as soon as the maintainer can manage. This is a small project, so there is no fixed timetable.

## What is in scope

Anything that would let information leave the device, let the page reach the computer beyond its narrow bridge, bypass the Parent PIN or School PIN, or read a protected backup without its passphrase.

## What is already known

[docs/security.md](docs/security.md) explains what is protected, what has been checked, and what is **not** protected (for example, the PIN is not device security and the saved data is not encrypted by the app). Please read it first.

## Supported versions

Only the latest release.
